## 两种使用方式

**先理解书中计算**：直接查看分析表及 `reference_results` 中的参考记录，按书中说明核对。

**亲自完成回测**：按指南建立独立练习副本，检查运行环境、自行获取外部行情，再运行回测和核验脚本。`reference_results` 保留书中参考值；自己的运行另生成 `results`。分析表不会因脚本运行而自动刷新。
